# Butter Bloom (Bakery Website) 🍰

A beautifully designed, responsive bakery website showcasing handcrafted cakes, freshly baked pastries, and rich, fudgy brownies. Butter Bloom brings together elegant design, delicious product collections, and a delightful shopping experience.

## 📌 Project Overview

Butter Bloom is a bakery website created to present a variety of sweet treats in an elegant and user-friendly digital space. The website highlights the bakery's products, brand story, customized celebration cakes, and customer experiences.

The design combines warm colors, sophisticated typography, beautiful food photography, and smooth interactions to create a welcoming bakery experience.

## 🎯 Project Goals

Create an attractive online presence for a bakery brand.

Present bakery products in a clear and organized way.

Provide a smooth and user-friendly browsing experience.

Showcase customized cakes for different occasions.

Build a visually appealing and responsive website.
